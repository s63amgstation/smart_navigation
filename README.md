App Idea 

1. 개요
복합경로에 대한 길찾기를 제안하는 실생활 밀착 어플리케이션

2. 현재 Pain-Point
경로 찾기는 단순히 네이버지도, Tmap 등의 앱으로 할 수 있고, 경유지를 추가하여 검색도 가능함. 예상시간 또한 측정이 가능함.
그러나, 경유지를 특정한 후에 계산을 건건이 해야하는 상황임. 
이에 애로사항이 2가지가 있음.

1) A → C를 이동하는 과정에서 가장 경유시간이 짧은 스타벅스 가 궁금할 경우 유저는 대략적인 근처에 있는 스타벅스를 검색해서 일일히 경유시간을 확인해야하는 번거로움이 있음.

2) A → D 를 이동하는 과정에서 B/C를 들러야 하는데 어디를 먼저 가야하는지 건건이 입력하여 최소 시간을 확인해야함. 또한 시간에 따라 그 위치가 변경될 수도 있어 모든 필터를 처음부터 걸어서 하나하나 확인을 해야함.

3. 시나리오
 - 메뉴 1 : 최소 경유지 찾기 (날짜/시간별도 필요)
 - 메뉴 2 : 시간별 멀티 경유지 찾기 
*이외 화면 시나리오, 기획은 추천 부탁

4. 제안사항
TMAP 무료 API를 활용하여 사용성을 판단하고자 함.
특정 서버를 띄우지 않고, 소스를 github pages 같은데 올려놓고 쓰게 만들고 싶어. 대부분의 사용자는 모바일에서 접속할 것임.
모바일에서 접속한 사용자는 자신의 집주소를 자기 iphone이든 galaxy등 추가 하고 재접속 시에도 이 부분은 남아있어야 함
검색시 자동완성을 지원해야 함. 
주소. 경유지 입력시 naver 지도 든 tmap이든 google map이든 지도가 뜨면서 어디서부터 어디까지 이동한다는 지도 이미지가 노출되어야 함.

# 실행 방법 (개발/로컬)

## 1. 구조
- **백엔드**: Node.js + Express (`server/`) — 정적 프론트 서빙 + TMAP REST 호출 프록시
  (브라우저에서 TMAP 를 직접 부르면 CORS 가 막히므로 서버를 한 번 거친다. 키도 서버에만 둔다.)
- **프론트**: 모바일 퍼스트 정적 페이지 (`public/`) — TMAP 지도 SDK + 자동완성 + localStorage

## 2. TMAP 키 설정 (코드에 박지 않음)
```bash
cp .env.example .env
# .env 를 열어 TMAP_APP_KEY 에 발급받은 키를 붙여넣는다
```

## 3. 설치 & 실행
```bash
npm install
npm start          # http://localhost:3000
# 코드 고치며 개발할 땐: npm run dev   (파일 변경 시 자동 재시작)
```
브라우저(또는 모바일)에서 `http://localhost:3000` 접속.
같은 와이파이의 휴대폰에서 테스트하려면 `http://<PC_IP>:3000`.

## 4. 기능
- **메뉴 1 — 최소 경유지 찾기**: 출발/도착 + 키워드(예: 스타벅스) + 시간 →
  경로 중간 근처 후보들을 각각 경유했을 때의 예측 소요시간을 계산해 최단순 정렬, 1위를 지도에 표시.
- **메뉴 2 — 멀티 경유지 최적화**: 경유지(최대 5) 순서 조합을 모두 예측해 가장 빠른 순서를 찾아 지도에 표시.
- 시간 기준은 출발/도착 선택, TMAP 타임머신(예측) API 사용 → 미래 시각도 가능.

## 5. EC2 배포 시
- 같은 코드 그대로 EC2 에서 `npm start`. `.env` 만 서버에 둔다.
- 프론트를 HTTPS(GitHub Pages 등)로 따로 서빙한다면 **EC2 API 도 HTTPS** 여야 한다(혼합 콘텐츠 차단).
  → EC2 한 대에서 프론트+API 를 같이 서빙(현재 구조)하면 이 문제를 피할 수 있다.

## 주의 / 한계 (프로토타입)
- 지도 SDK 특성상 appKey 가 클라이언트에 노출된다(프로토타입 한정). 운영 시 키 도메인 제한 권장.
- 호출량: 메뉴1 = 후보 수만큼, 메뉴2 = 경유지 개수! 만큼 예측 API 가 호출된다. 후보/경유지 상한으로 제어 중.
- TMAP 예측 API 의 요청 필드명(predictionTime/searchOption 등)은 `server/tmap.js` 한 곳에 모아둠 →
  실제 응답이 다르면 거기만 수정.
